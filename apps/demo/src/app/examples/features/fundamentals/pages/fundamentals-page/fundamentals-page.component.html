State shape becomes the API.

Start with one object. SignalTree preserves its shape behind $, gives leaves signal-style writes, and declares derived values in the same construction call.

Curated sequence

Four steps before specialized concepts

01

Declare state shape

The initial object defines the paths consumers can read.

signalTree({
  cart: { itemCount: 2, unitPrice: 24 },
  customer: { name: 'Ada' }
})
02

Read through $

Roots and branches are callable accessors; leaves are reactive cells.

tree.$.cart()
{{ tree.$.cart.itemCount() }} items at {{ tree.$.cart.unitPrice() }} each
tree.$.customer.name()
{{ tree.$.customer.name() }}
03

Write leaves explicitly

Leaves use set() and update(); a value call is never a setter.

{{ tree.$.cart.itemCount() }}
04

Declare derived state once

Angular-native computed() values join the tree through the construction config.

derived: ($) => ({
  subtotal: computed(() =>
    $.cart.itemCount() * $.cart.unitPrice()
  )
})
