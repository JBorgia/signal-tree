Choose a boundary before a container

  • Independent form or connection lifetime → a separately owned tree or native local form state.
  • Dynamic data rows under one owner → a declared entityMap().
  • Combined display → computed reads or a tree registry, without copying state.
  • One atomic operation across trees → not supplied by this pattern. Design that boundary explicitly.

This example adds no runtime slice API, private kernel hooks, transactions, or restoration. Add an enhancer only when the application needs its behavior.
