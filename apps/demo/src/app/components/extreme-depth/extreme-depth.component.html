Why this test exists

Deep runtime data can outlive its useful type

A JavaScript object can nest far deeper than TypeScript can always describe ergonomically. Libraries commonly map a state type recursively into readers and writers. At greater depths, an unsafe shortcut can widen a leaf to any or unknown, while a very complex recursive type can hit TypeScript’s instantiation limit.

Runtime clicks cannot detect that loss. This page’s generated source is compiled by the normal strict typecheck. Each offered depth fails the build unless the deepest leaf remains exact and the IsAny detector stays false. The browser test is separate evidence that the generated path also works at runtime.
