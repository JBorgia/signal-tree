Causal application state

Model nested state as data — not reducers, selectors, and ceremony.

SignalTree keeps authored work, external truth, stable identity, and multi-entity operations coherent as state gets deeper and applications get larger.

Reactive JSON means your state still looks like data. Keep one runtime tree, compose typed slices, and add EntityMap, DevTools, transactions, or restoration when those capabilities earn their place.

SignalTree is not @ngrx/signals. Different library, different package (@signal-tree/angular) — no withState/withMethods wrappers, no actions, no reducers. Your state literal is the API: read and write any path directly, at any depth.

Use SignalTree if you need

  • Coherent operations across several state locations
  • Stable EntityMap identity through structural changes
  • Typed normalized collections with O(1) lookups (entityMap)
  • Angular-owned forms and application-owned persistence alongside one typed state authority
  • State that mirrors your data shape, not Redux ceremony
  • Optional restoration for explicitly reversible operations
