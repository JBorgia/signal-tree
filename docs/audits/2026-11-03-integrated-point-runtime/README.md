## Mechanism and cause

[Design and frozen premises](DESIGN.md) describe source-issued point packets, unchanged aligned topology, opaque native-only completion, exact pending-membership snapshots, lazy private collection-version realization and fused field facts with exposure/reentry/retirement guards. Value merge/deep equality and native history remain intact; no public exports changed.

The reduced generic point preparation produces the count and CPU improvement in this integrated artifact; this run does not assign gains to individual changes. Fusion also introduces per-row wrappers, order arrays and revision tokens, plus per-field pair wrappers. [Source accounting](field-layout-cost-explanation.md) establishes extra explicit objects despite fewer Maps. That is a concrete layout cost and a plausible explanation for increased storage, **not a measured attribution of the extra bytes**. The next technical question is a smaller representation preserving independent side order and exact endpoint/View identity. This experiment does not admit or run that replacement.
