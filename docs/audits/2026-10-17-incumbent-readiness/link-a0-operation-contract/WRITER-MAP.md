## Equal-retained and failure details

kernel commitRecorded (tree-scalar-slot-runtime.ts254–282) checks displayed/ordinary equality, validates revision after equality and terminal prep, installs values+terminal plan callback-free. Equal physical+ordinary returns changedfalse without new value evidence. Writer STILL calls reAdd; equal retained value under dormant path can be meaningful membership installation even when no scalar slot mutation. No forced equal-value revision emission is implied.

Partial sibling failure in recursiveUpdate is observable existing behavior: per-key source units install before later equality/updater/marker reflection. New A0 evidence must capture what installed before failure and retain recovery; may not pretend an uninstalled prepared whole branch exists or delete earlier/reentrant work to satisfy fabricated atomicity.

## Capture callback reentry: what is proved

Native source directly invokes mutationSource.capture synchronously after commitRecorded and before reAdd. This is a function callback, not terminal installation's callback-free section. Existing source makes no local guard preventing it from causing further source writes; structural/transaction consumers may subscribe internal capture ports. This map does **not** establish an ordinary public app callback directly wired to mutationSource.capture; that requires tracing actual capture installation/registration and supported custom enhancer hooks. Accordingly it is unsafe to assert 'capture cannot reenter' from current code, but equally unsupported to label arbitrary monkeypatch reentry as a public producer.

Moving reAdd before this callback changes its observable absent/present read if any supported capture subscriber reads the path, and changes ordering versus branch-member publication. Preserve current timing by explicit value-installed and membership-installed units until reachability review proves coalescing safe. prepareTerminal hook is earlier, may run user-reflecting preparation and has existing revision guard; moving capture itself there would change its after-install semantics.

No new public semantics or API selected. This inventory's minimum is honest per-lane installation evidence, not universal value+membership atomicity. Sequence tokens distinguish installed units; transaction owner remains existing scope, callback-authored reentry is a distinct operation even when same owner.
