EntityValueStore preparation inside the existing frame revision window. The
ordinary footprint uses own enumerable string presence and Object.is comparison,
matching established field-diff semantics. Nested references are not deep-cloned
before comparison. Data-only returned rows retain their exact reference. Own
enumerable accessors are evaluated once with the original receiver; their staged
values, other descriptors, symbols/nonenumerables and prototype form the physical
result. That same result is installed and forwarded to notification/taps.
Authorship restriction does not discard unrelated physical data. Explicit whole
replacement retains its prior path. There is no new rollback or publication owner.

repair fixed getters but discarded physical properties and reference identity;
independent comparative probes rejected it. Descriptor preservation and data-only
identity retention close those probes. No universal arbitrary Proxy/reflection or
process-OOM guarantee is claimed.

## Remaining public Link counterexample

Use a tree with `{rows: entityMap()}`, add `{id:'a', value:1}`, bind Link to the held
`value` field, then `replaceOne('a',{id:'a'})`. There is no pending transaction.
Physical field becomes undefined and notification arrives, but no outbound send
occurs; settled remains outstanding through the finite drain and only resolves on
disposal. With transactions installed, otherwise identical operations send undefined
and settle. The ordinary name `value` rules out collision names as the cause.

The experimental eligibility receipt is `unknown:true` without transactions and
`unknown:false` with it. private.ts marks evidence unknown when the owner token is
absent. This locates eligibility/owner initialization as the first discriminator;
it does **not** yet completely trace the missing conservative-fallback grant/wake.
Eight unchanged 5-second timeouts support sustained failure; the finite diagnostic
alone is not proof of permanent holding. JSON converts undefined array entries to
null, so the raw SEND line explicitly distinguishes the actual undefined payload.
Root independently replayed the reviewer bundle and observed the same result.

No requirement for transactions on ordinary Link trees is selected. No Link repair
or declaration bypass was made. This unresolved integration boundary remains separate
