## Bounded result

The original model snapshot preserves the earlier independent-frame behavior. Its three added tests express the actual counterexamples: outer argument copied by nested callback, nested callback return consumed by caller, and nested callback writing a captured local. The supplied first-red output records 15 passes / 3 failures, each failing because the copied value incorrectly became eligible.

The sole model delta changes frame construction to union parent and child inputs and joins child facts back into parent in finally. The supplied subsequent output records 17 passes / 1 failure. All three copy witnesses now pass. The preserved original nested test still requires `outer` to become eligible after p confirms while q remains pending; it instead stays held because the nested b callback adds q to its parent. This is a real liveness failure against that preregistered assertion. It must remain failed, rather than be reclassified as a successful safe implementation.

This falsifies these two simple frame policies against the combined bounded assertions. It does not prove no finer-grained implementation or different explicitly authorized execution-boundary contract can satisfy the requested capability. The experiment is appropriately stopped without exception branches or weakened assertions. The original test's promise of an independent outer constant after a nested callback is stronger than merely allowing a fresh top-level unrelated write, and stronger than the SPEC's acknowledged conservative constant-after-read policy. That distinction is a scope/semantics question to resolve before another candidate, not a reason to silently rewrite the oracle.

## What the kernel probe establishes

The probe builds repository kernel source without source substitutions, recording hashes of loaded kernel TS files. It constructs two separate neutral trees, each with pending x=7, a notifier observation of x, and Link on y. Both cases cross an await boundary. One writes a captured notification argument; the other writes literal 7. The script compares normalized returned traces with assert.deepEqual and asserts that y has no transactionId or active write context, sends nothing while x is pending, and sends [7] after confirmation. JSON and first log agree with those assertions.

This is concrete evidence that this pair has indistinguishable **recorded delivery metadata and outcomes**, modulo normalized owner/id numbers. It also confirms the incumbent conservative hold covers both the dependent copy and independent constant in this workload. It does not demonstrate the independent-progress requirement: the direct arm is held too. The direct arm is an asynchronous constant write after the same prior x notification exposure, so this result must not be described as a test of every direct synchronous input boundary.

The trace is not a complete runtime trace: the probe drops notifier owner-path, origin, subject/position arguments and does not record all internal operations, read events, JS lexical behavior or scheduling identity. Source inspection explains why these scalar replacements provide no existing closure-provenance carrier, but equality of this observation projection alone is not a universal impossibility proof. The control intentionally makes both runs observe x; provenance that records exposure rather than actual use will conservatively classify both. Additional trusted input or application instrumentation could distinguish them, at a cost and contract still to be decided.

The probe covers confirmation only, not rollback, rejection of delayed captured truth, nested settlement or native framework effects. Forty microtask turns are a bounded pending observation window, not an assertion of all eventual schedules. The later awaited Link settlement provides the positive confirmed-send control.

## Required boundary decision and remaining unknowns

The hypothetical `input` authority in the model is legitimate for a conditional experiment, but it is not an existing production hook or an approved public API. A future proposal needs to identify which real execution boundary proves fresh independent input, which dependencies flow through nested callbacks/returns/captured locals, and which unobservable cases are held or outside the supported claim. A blanket “no active metadata means clean” classification remains unsupported. Blanket propagation can satisfy the demonstrated copy safety while failing the preserved nested liveness assertion.

Native cached computed reads remain untested here: the probe imports the neutral kernel only, and the model's read method explicitly supplies labels. Prior source evidence shows native cells/computeds are returned directly and cache hits need not invoke kernel reads. Whether a suitable native observation hook exists or can be added under the existing ownership contract is unknown; this paired probe neither establishes nor refutes it. Equal attempted writes, production token reclamation, compensation ordering and teardown remain bounded-model limitations from the earlier review.

Final disposition: preserve failed model outcomes and successful narrow kernel-observation control as research evidence. No integrated candidate passed; no production behavior, public API or architecture is accepted. The evidence identifies an execution-boundary decision and missing instrumentation; it does not establish universal infeasibility of independent Link progress.
