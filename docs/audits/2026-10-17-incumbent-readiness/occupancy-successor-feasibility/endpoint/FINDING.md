# Endpoint encoding feasibility — bounded result

Experimental per-lifetime endpoint composition can express the preserved occupancy assertions through the existing incumbent rollback-effect generator. This does not qualify the actual capture pipeline, installation, dependency or publication behavior.

## Provenance and first results

`original/` contains verbatim original probes, compiled sequence, first failures, extracted incumbent fold/rollback bundles and source identities. The active `probes.mjs` and `compiled-sequence.mjs` are byte-identical to originals; only their locally resolved `fold.mjs` dependency differs. The original harness's printed scope string still says “extracted incumbent structural fold”; that string is stale for this run and preserved for exact harness identity. Correct attribution is: NEW experimental endpoint composer → existing extracted incumbent net-effect conversion → ACTUAL existing createPendingRollbackEffects. This is not 8/8 success of unchanged incumbent normalization.

First endpoint run: 8/8 original assertions, plus unchanged compiled-sequence assertion pass. Six supplemental model-boundary discriminators pass. They show separately supplied explicit field effects survive same-key occupancy cancellation and net relocation in actual inverse generation; independent input capture intervals remain separate; previous returned records remain unchanged; discontinuous input is rejected.

A subsequent payload-context discriminator failed: initial endpoint encoder lost original add value and neighbor context after add→rekey because it selected the last rekey record for add context. `fold-first.mjs` and `payload-first.log` preserve this failure. The corrected model retains the actual last add context while adjusting its net key. Unchanged payload discriminator now passes. All prior assertions reran after that model-only correction; final logs are separate. This illustrates that an occupancy endpoint alone is insufficient to reconstruct value/placement facts; those facts must travel independently.

## Scope

The model does not install state, select ownership or resolve placement. It aggregates structural input by collection/lifetime, verifies each next before-key equals previous after-key, retains initial/final occupancy, emits add/remove/rekey/no occupancy effect, then feeds those into incumbent conversion and inverse generation. One map exists only for the supplied capture interval; it is not a canonical store or new settlement engine.

Values in the original occupancy controls are constant per lifetime. Explicit field discriminator effects are separately supplied; no native producer/capture correctness is claimed. Preserving an add's neighbor metadata is not order-policy qualification. Full order descriptors use a different native channel, which this harness does not integrate.

The “committed” and “nested” controls exercise separate arrays/calls, NOT native committed or reentrant runtime scheduling. In particular, nested work consuming a temporary placement followed by outer return to starting occupancy remains UNTESTED. Actual later-dependency predicates may need transient authored facts despite zero net occupancy. This model must not erase operation chronology, responsibility observation or dependent facts merely because endpoints coincide.

The actual paired-responsibility scratch and foldOperationDisposition also use enqueueEffect. None was changed. Atomic paired installation, capture checkpoint segmentation, inspection chronology, actual dependency checks, physical-before-validation relocation and collection retirement remain unqualified. The model does not clear the recurrence stop or authorize integration.

## Conclusion

The earlier remove→add failure does not prove the existing effect vocabulary cannot represent the constant-payload net occupancy result. A generic endpoint encoder can produce that result and existing inverse generation retains it. It does prove chronological Bind output cannot be fed unchanged into the old fold. A successor requires explicit coherent adaptation at every capture consumer plus preservation of nonoccupancy facts and operation chronology; this isolated expressiveness result is necessary evidence, not that adaptation.
