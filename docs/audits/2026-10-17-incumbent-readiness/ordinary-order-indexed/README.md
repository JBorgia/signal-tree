## What changed

One source owner maintains current ordinary presence, key and adjacency exceptions
relative to physical placement. EntityValueStore remains the only persistent
payload owner. Preparation visits the union of changed ordinary and physical slots;
installation normalizes only those slots and updates the associated key index.
Physical-only changes therefore preserve ordinary facts before overwriting their
fallback. There is no whole-divergence-map scan during local normalization.

Native recovery/history claims retain their existing authority and lifecycle.
Ordinary-present, physically absent lifetimes protect their backing from premature
reclamation. Recovery-only facts do not become current placement authority. The
standalone model separately exercises exact fact identities, per-lease membership
and last-obligation reference counts; it is not a new production lease engine.

Complete prepend placement is prepared before callbacks and capture. Fresh inserts
resolve ordinary anchors through physically visible but ordinary-absent lifetimes
without adopting them. An already-satisfied existing-row prefix does not change
ordinary order. A real prefix movement or full reorder carries separate physical
and ordinary endpoints plus the authored domain. Selected inverse installation
permutes that domain while preserving omitted current ordinary members. Existing
occupancy/dependency/order-frontier validation still decides whether settlement
may proceed.

The private selected-inverse marker identifies disposition already chosen by the
incumbent. Original ordinary operations continue to respect each Link's adopted
baseline and latent physical topology; source responsibility is not substituted
for a connection's baseline. Root and nested collections consume the same private
handoff. No Link flush, output filtering, global baseline reset or new API is used.

[Independent cumulative review](CUMULATIVE-REVIEW.md) maps all six installation
routes and states its limits. [Model review](MODEL-REVIEW.md) independently verifies
the indexed normalization and recovery lifecycle.
