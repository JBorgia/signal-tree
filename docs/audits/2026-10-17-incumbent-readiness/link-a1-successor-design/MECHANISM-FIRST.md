## Three independent representations

1. Native physical membership is the existing descriptor pair. Native ordinary
   membership needs one explicit, identity-validated sparse divergence record at
   that same source. Existing native scalar/entity stores still own values.
2. A Link relationship owns its eligible projection under its existing creation
   baseline. It consumes prepared ordinary deltas in native installation order.
   It is not a native ordinary store and cannot select an inverse.
3. Each relationship fact carries publication support. A projection revision
   combines only contributing facts. Receipt terminality does not retire a still
   contributing fact, nor does a fact give a retired receipt new life.

The first addition supplies a missing native fact. The second is an ordering
correction to the existing eligible reducer. The third extends the scalar-shaped
experimental support mechanism to the owner-approved aggregate scope. They must
not become three competing answers for ordinary values or settlement selection.

## Whole-operation private publication admission

The heterogeneous reentry failure is caused by per-row prepared publication
running after a callback has authored a newer row. Moving taps alone is not a
complete remedy: notifier enqueue observers and synchronous notifier mode can
also reenter, as can native invalidation/effect delivery.

Prepare a publication packet for the entire existing callback-free installation
unit. It contains ordered exact O edits, separate P installation facts, native
identities, captured source input proofs, and the affected relationship indexes.
For atomic selected settlement, all constituent row/member/order edits belong to
that selected prepared unit. A branch method that already installs partial units
retains those boundaries; it is not made whole-method atomic. Reentrant writes
are subsequent units, never folded into the outer unit's final after-image.

Admission and pending-completion registration occur with native installation and
minimum responsibility, before native invalidation, rich capture, path enqueue
observers or taps can execute. Private reducers process installed units in their
source order, even if public callbacks are delivered in another order. They use
immutable selected ordinary deltas, not a post-callback reread of physical rows.
No user getter/equality/reporter executes in this primitive admission interval.
Projection allocation/reflection is prepared before that interval and revisions
are revalidated after user-code preparation.

Preserve current public/native notification timing. Link's existing eligible
reducer consumes the admitted delta once. A later public notification can wake
work and provide diagnostics but cannot replay an older unit into a projection
which already consumed a newer unit. Associate notification metadata with admitted
unit identity only for deduplication/audit; metadata never creates authority.
A unit without a public value event still has completion work. Reduce nothing
from a discarded/uninstalled plan. A relationship created after installation
starts from its own baseline and cannot inherit that old declaration.

The normal conservative Link path must use this same chronological projection
consumer for migrated sources; otherwise correcting only declared publication
would leave the public default-Link reentry counterexample intact. Conservative
eligibility remains unchanged. Unmigrated source routes remain explicitly
unqualified; one optional hook cannot claim coverage of all related writers.

Invalidation and public delivery attempt every already-installed constituent,
with existing primary/secondary error handling. An error cannot prevent later
invalidation or strand completion. Terminal owner outcome follows coherent
native/projection disposition. A started immutable transport packet may finish;
new eligible truth follows through the existing serialized corrective send. No
extra flush or arbitrary timer supplies either chronology or eligibility.

## Aggregate support and receipts

Replace A1's single valueFact/valuePayload binding with stable field and structural
fact slots feeding the existing relationship reducer. Own authored-input proofs
and untouched supporting proofs remain separate. Source→relationship indexes
reach ancestor aggregates and descendant lifetime/member dependents. Point work
visits affected subscribers/facts/dependencies; initial source enrollment, full
outputs and explicit broad order operations may enumerate their real domains.

Actual native updater inputs are captured before user callbacks. Declared hidden
inputs remain the application's responsibility. Existing enclosing validation
horizons remain binding across connections and must finish before early release.
Untouched sibling/ancestor/lifetime/key/order support can hold a valid declaration;
actual omitted inputs still contradict it. Full replacement authors only its
native footprint, not every physical fact visible afterward.

A projection revision supersedes an older unstarted receipt, but its live fact
proofs stay indexed independently until replaced, masked without a surviving
obligation, or released. Confirmation wakes affected live facts even after their
introducing receipt was superseded. Rejection invalidates prior permission; it
cannot publish the old speculative payload just because an owner is terminal.
Native selected inverse and genuinely fresh ordinary replacement remain distinct.

A real no-op with unchanged effective support has no new revision. Equal-value
support replacement can be meaningful without a user value event. Pending work is
visible to settled() before completion; disposal retires it and separates in-flight
transport from queued work. User-retained terminal receipts hold detached result
cells, not source/connection/proof/payload graphs.

## Replacement, not additive authority

- Native sparse O presence replaces descriptor-only ordinary-presence inference;
  descriptors still own P and existing incumbent machinery selects settlement.
- Whole-unit private admission replaces per-row notification-order reconstruction
  of Link eligible truth; public notification protocol remains for observers.
- Aggregate field/structural slots replace the scalar-only latest-value authority;
  relationship-local baseline/reducer and transport queue remain single instances.
- Live fact proof indexes replace receipt/operation lifetime as the sole dependency
  retention root. No additional history or compensation selector is introduced.
