# Reference artifacts

Published or point-in-time documents kept for the record: whitepapers, case
studies, protocol rulebooks, strategy and monetization papers.

**These are evidence, not live documentation.** They are excluded from the
documentation link/install gate, because a document is judged against the state
of the world when it was written — a whitepaper that expects a `figures/`
companion set is not broken repository documentation, and editing it to satisfy a
checker would corrupt the artifact.

> **A REFERENCE ARTIFACT IS NOT A LIVE DOCUMENTATION SURFACE.**

Live documentation — README, current guides, API docs, current migration guides,
release instructions, package READMEs, examples — stays outside this directory
and is gated normally.
