## Deliberate limits / uncertainties

- Private source evidence and registered location interception are explicitly used in support/continuation cases. The single combined spec is not advertised as a wholly public black-box consumer.
- The proposal requires equal transformed sibling authorship to replace earlier selection. These identity assertions follow that explicit requirement; if the implementation lacks source-issued support for such a step, that is a mechanism gap, not grounds to assume equal values imply equal authority.
- Opposite order is pinned to the frozen experimental route (reverse field-write order), not inferred from the retained87 public comparison, which had different order. Any deliberate change to selected effect order must be reported before altering this oracle.
- Delivery may contain or propagate errors. This suite tests whole-unit state/terminality in either case. It does not claim the transaction catch branch executed merely because a tap threw.
- Prepared-phase reentry changes mean the original immediate-install double-proceed test cannot be copied as an active oracle. It remains archived elsewhere; this suite preserves no-reuse while asserting the authorized preparation boundary.
- No new readonly/carrier/type contract, getter-count total, heap guarantee, structural coverage, or full release acceptance is inferred.
- Missing or renamed private source-evidence seams require explicit fixture adaptation review; never skip a case or return early to manufacture a pass.
