## Mechanism actually implemented

- Existing MATERIALIZED records and SNAPSHOT_PARENT weak ancestry moved, not duplicated, into private `snapshot-installation.ts`. That module imports only node-shape at runtime and cell types. Source runtime hooks do not import snapshot-authority/location-runtime back through it, avoiding the eager module cycle.
- Demand-created ancestry now includes terminal owners and the missing symbol accessor edge. Scalar install hooks use C8's existing actual publicationSources binding; no position/path reconstruction or new slot lookup graph.
- Complete physical installs advance existing demanded record generations along ancestry before callbacks. Presence changes dirty affected retained descendant branches as well as parent. No build or token publication occurs in these hooks.
- One retained observe per memo. Actual observe recomputation ALWAYS uses the existing tracked builder; no generic dependency-touch mode. An early current-read cache can win at the same generation, preserving returned identity while permitting a temporary tracked output. Normal observer recomputation without an early winner still accepts newly built output, including dependencies without an install hook.
- A per-invocation receipt records whether observe built. A generation-changing attempt returns its existing current-call outcome without caching or an automatic second attempt. Exceptions propagate; receipt cleanup uses finally. No new retry loop, cycle exception or fallback error policy.
- Native snapshot terminals perform the native reactive read for dependency tracking, then read installed backing through a private weak registration preserving live attachment and absence. Native mirrors are not committed early.
- EntityMap marking is attached to the FOUR existing R4 `installedReadRevision` advances, using the actual returned proxy identity. `createVersionedProjection`, allSignal, getter/tap behavior and collection revision ownership are unchanged. No additional collection epoch/cache or graph.

There are nine modified baseline runtime files and one new private runtime module. No framework package runtime, public barrel, adapter contract, manifest, lockfile or type baseline changed. `RUNTIME.patch` is the runtime-only delta; `FROM-C8.patch` includes the unchanged parent controls and new proof fixtures.
