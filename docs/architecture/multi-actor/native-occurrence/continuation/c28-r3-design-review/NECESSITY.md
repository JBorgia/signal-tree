# Necessity challenge: closure at admission versus temporary comparison

Revised conclusion: I do not establish recipient aggregate admission-closure as a frozen public semantic or a necessary condition for temporary no-write comparison. It is a conservative internal R2/design restriction on historical normalization. My earlier REVIEW.md overextended that restriction when requiring a broad proof-version closure representation before any B experiment. A narrower comparator-only experiment is justified with the obligations below. This does not select an implementation or relax existing source cleanup/validation gates.

## Authority and distinction

CURRENT-SPEC.md:42 preserves native obligations, nested validation and final relevant revision semantics; it does not prescribe the time at which a recipient aggregate must have become closed. The owner's specific approval makes already-confirmed irrelevant I/V history immaterial to fresh equal no-write while preserving current obligations, fresh validation, old issued evidence and receipts. R2's admission-closure test was introduced as an implementation restriction protecting source projection, not as a newly approved public receipt rule. Existing tests protect actual obligations and progress; an internal condition must not be promoted into public policy by inference.

Three permissions must remain separate:

- Source normalization: keep existing P/S/consumed-history admission closure, current readiness, raw validation and retirement rules.
- Recipient dependency/proof mutation: keep existing bounded permission; a comparator predicate does not authorize pruning an old operation or rewriting issued proof.
- Temporary equality: derive disposable comparison views without changing either operand, its owners, listeners, stored proof, or receipt. This narrower operation can use a broader discovery domain than source normalization without acquiring broader mutation permission.

## Conditional correctness argument

Let t be a fixed admission cutoff and L the current captured-pending/frame-entry lower bound. For an exact authentic cell define E(c) only when its immutable first confirmation fact is at or before t, it remains confirmed, and c is not in L. Missing metadata is ineligible. Define Q on a proof to remove only eligible I/V memberships and corresponding aggregate owners, while retaining identities with D/W/unclassified roles. All flags and all other memberships are unchanged.

At ordinary final reduction compare Q(actual prior) with Q(actual effective), in addition to the unchanged value/clean conditions. Current raw declaration validation and activation must already have completed; installed source/occurrence support remains governed by its existing gates.

If this comparison succeeds, every differing role membership belongs to an already-confirmed, unprotected I/V cell. D, W, pending/abandoned/rejected identities, current captured lower bounds, unknown/invalid/unavailable/rejection/historical-window flags and value/clean state agree. Under the approved relevance rule these differences do not create new publication responsibility. Keeping the old receipt as sender does not erase its finite issued proof/dependencies, nor permit the new declaration to skip validation. The new operation can follow the existing noWrite path; current source installation still occurs.

This argument does NOT depend on whether an old I/V cell was enumerated at admission or whether the prior proof itself became complete before t. It depends on when the cell confirmed, current capture protection, and the actual authoritative proofs at comparison. An old certificate open at t can close later with the same irrelevant confirmed a; its later completion alone does not make a pending responsibility. If it instead introduces pending q, rejection, invalidity or unknown evidence, Q retains those differences. If q confirms after t, the immutable cutoff excludes it even if reduction sees it confirmed. If q was captured pending but confirms before t, L excludes it. Fresh confirmed validation a must still undergo completeness checks before any Q comparison can affect the receipt.

The measured n2 satisfies this narrow case: old a confirmed before the new admission, is absent from current captured lower bounds, and differs only in old I/V/owners. Temporary Q classifies it without retaining a historical owner list and without mutating the old receipt. Tentative siblings can be compared after their ordinary reduction resolves the actual prior; no enumeration of both histories is necessary merely to classify confirmed cells at that point.

If only the prior side is projected, this suffices where the effective side has already been normalized under existing source permissions (as in n2). It can conservatively miss equivalence elsewhere. Symmetric temporary Q views implement the stated equivalence more generally; neither view may become stored normalized proof by accident.

## Concrete remaining failure boundary

“Final reduction” must not be assumed from the existence of a proof object. Frozen R2 private.ready waits unit invocation and, conditionally, native readiness; it then obtains aggregate support and records index.unresolved()!=0. Proofs may also be replaced by occurrence callbacks. A temporary comparator must not collapse an operation on an incomplete provisional proof that can later acquire relevant evidence without the retained operation being governed by it. For example, a still-open contributor can later add invalidity or a pending q absent from the prematurely compared proof. A time predicate does not prevent that failure.

The needed obligation is readiness/stability at the comparison or an existing demonstrated mechanism preserving that later evidence—not closure before admission. A local final-readiness guard can conservatively exclude unresolved aggregate comparison. It must use actual aggregate support/current validation, not only one leaf factRequirements. No new permanent proof-version chronology is proven necessary for this guard. If callback-capable reduction can replace the selected prior between reading it and selecting noWrite, existing reentry/install validation must cover that interval or a local consistency check is needed. This is a bounded source question, not evidence that a broad history model is required.

Do not require all owners terminal as a substitute: p remains legitimately pending throughout the approved workload. Requirement finalization/activation and owner settlement are different conditions. Do not remove source P/S/input closure, weaken the genuine-open-history test, or use temporary comparator eligibility in reconcileCurrentDependencies for the old operation.

## Minimal bounded experiment / falsifiers

Preserve original repeated-no-write n1–4 plus terminal/disposal assertions; compare only ephemeral proof views using fixed confirmation facts and L. Keep old proof/dependencies byte/identity-stable as existing controls require, source cleanup and retirement unchanged. Include both sibling keep/collapse outcomes and reversed order with actual final aggregate readiness recorded.

Pair two open-at-admission cases without changing existing tests: one completes with only already-confirmed irrelevant I/V differences; another introduces pending/invalid evidence before completion. The latter must not be equated or sent early. Keep confirmed nested-validator contradiction, pending-captured-then-confirmed, post-cutoff confirmation, opaque dual obligations, and existing error/readiness controls. A synthetic incomplete proof read before closure is only a model falsifier unless tied to a supported runtime path.

No concrete counterexample has been found to this restricted, finalized-proof comparison argument. There is a concrete counterexample shape to comparing provisional proofs, and frozen R2 does not by source inspection alone prove every aggregate operand finalized. Therefore approve investigation of the narrow comparator boundary, not a blanket claim that R2's present reduction point already satisfies every premise.
