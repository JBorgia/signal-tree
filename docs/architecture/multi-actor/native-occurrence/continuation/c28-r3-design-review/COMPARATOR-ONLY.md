# Narrow comparator-only option: independent resolution

Decision: eligible for a bounded private implementation experiment. No actual counterexample found showing leakage or false suppression under the stated premises. Rejecting it merely as “comparator-only incomplete” would be unjustified. Different consumers legitimately have different cleanup permissions.

The proposed delta leaves R2 source transport, new-operation projection and dependency reconciliation unchanged. Only disposable comparison views use an immutable first-confirmation-before-admission predicate plus frozen current captured-pending protection. D/W/unclassified roles and every flag are preserved; value/clean tests stay intact. Current raw validation/activation completes first. Neither issued prior nor effective stored proof is rewritten.

Source argument: private.ready installs current field/occurrence support before obtaining aggregate effective proof and comparing to proofs.get(unit.previous) (R2 private.ts:337–350). A successful comparison then follows existing lifecycle.noWrite, which removes the new operation and either preserves the established receipt fallback or marks the fresh receipt no-write; the old operation is not rewritten (lifecycle.ts:409–418). Current source support remains installed. Thus correcting equality does not remove an old pending dependency or grant a new early-publication permission. In n2, the removed comparison difference is confirmed a in historical I/V/owners only; p, D/W and all flags already match. Keeping the original sender is the approved result.

More generally, if the two temporary views compare equal, any ignored difference is an authentic already-confirmed, unprotected I/V membership. Such a cell cannot subsequently become pending/rejected: ownerTransition forbids terminal reversal. A current captured-pending cell cannot qualify merely by confirming in the callback because protection survives. Confirmation after admission cannot qualify by the time of reduction. New pending/rejected/unknown/invalid/unavailable or D/W differences remain visible. Raw current completeness checking must still reject missing contributors before this equality can determine receipt attribution. On these premises, suppressing a new operation represents historical equivalence rather than loss of a live obligation.

The original old operation may retain more confirmed history than current support; that is its finite issued lifetime, not permission to append later history or keep new comparator descriptors on it. The implementation must release temporary descriptors normally. No general reclamation claim follows from equality.

Readiness boundary: private.ready processes the pending Set in installed order and breaks on incomplete current units/invocations. A tentative preceding sibling is therefore reduced before the next sibling compares; its same-horizon invocation is complete, and no-op fallback resolution uses existing effectivePredecessor. This supports the measured sibling case without requiring admission-closed recipient history. However, ordered pending reduction alone is not a proof that every unrelated aggregate occurrence is resolved: the code separately tracks index.unresolved(), and selected/native support can differ from the unit invocation. The narrow implementation must establish finalized actual comparison operands (or conservatively guard unresolved aggregate cases) without requiring pending owners such as p to settle. This is a focused qualification obligation, not an executed counterexample to the proposal.

Keep unchanged repeated-no-write, A/B, raw validation, opaque and terminal/error controls. Add the cheapest exact guard witness: both sibling keep/collapse orders, and an actual unresolved aggregate contributor that resolves after an attempted reduction. Confirm no premature equality and useful later progress. No need to give source normalization or reconciliation the broader comparison predicate; doing so would enlarge the proposed change and require separate review.

No runtime edits or execution. This resolves the premise in favor of bounded eligibility, not final acceptance of an unseen patch.
