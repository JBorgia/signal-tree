# Frozen source excerpts

Copied historical contract documents and raw review prompts are compressed when their repository-relative links would misleadingly appear to be live documentation here. Decompression reproduces the original bytes; each packet's ARCHIVE-MAP.json retains original and archive hashes. This is archival packaging, not a change to the source contract or a suppression of live documentation errors. Reports and current guidance remain ordinary Markdown and are checked normally.
