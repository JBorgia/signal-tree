It does not take authority from notification coverage or the declaration stack. Contribution facts are distinct from the outgoing fact; outgoing eligibility is composed from the complete occurrence index. Ordinary authored completion can replace the wrapper for its own contribution, including support-only equal writes. Current stale-contribution filtering is unchanged. Unknown source-field resolution does not silently replace every sibling's support.

An observed outgoing revision is registered with the existing lifecycle operation/dependency mechanism, with no declaration frames, views, permission or new owner window. Its existing owners/possible cells can wake it; existing started/supersede/dispose paths retire it. This small lifecycle addition was necessary after the first implementation preserved safety but lost useful settlement wake-up. It does not acquire dependencies by scanning globally pending owners.

No public exports, activation, ownership policy, budgets, source-issued identity redesign or caller patches. Broad unsupported projections are not qualified by this bounded scalar work. The private new `observeRevision` module function is not a package export.
