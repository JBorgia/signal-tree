The updater consumes the whole genuine native root argument. qi confirms before the next transaction is created. No fabricated owner, private tag, replaced callback, invented terminal event, or manual role mutation is used.

## Source interpretation and limits

lifecycle.captureNativeInput filters already-confirmed owners only from NEW capture. Each qi here is pending when captured. Later combination preserves earlier selected role sets; finish freezes the proof and clears scaffolding without removing those cells. C26's normalization replaces ancestry with the same roles, so it intentionally leaves this history visible. This execution confirms the earlier source finding with a fixed-size public state and recipient.

Instrumentation only adds read access to selected endpoint/view/bindings, fact requirements and existing retirement/listener weak edges. It does not change decisions or notifications. The graph walker enumerates own data properties, Map/Set entries and these explicit weak associations; it cannot enumerate arbitrary closure environments or all VM roots. It does not retain a list of prior endpoint snapshots or qi handles to manufacture the source-role count. Counts are structural identities, not heap bytes, GC, CPU or timing measurements. This is a finite0/1/2/4 demonstration, not a general measured growth law.
