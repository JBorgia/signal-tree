## Finding and supported boundary

The four native-local admission checks are both expensive and incomplete. `experimental-publication/entity.ts:100–108,219–222` captures/indexes structure and checks around native preparation/finalization. `internals/entity-publication.ts:168–191` then calls recipient finalizers after the native finalizer. The independent late append therefore installs a record prepared for 7 after the packet gains 99. This is an inherited private-seam hole contradicting the new guard claim, not a demonstrated public payload exploit.

Actual producers construct packet metadata in `entity-signal.ts:1409–1422,2336–2339`; responsibility receives selections/capture, not this packet. Deferred points collect packets and build a final packet in `internals/entity-publication.ts:262–268`. Readonly private types promise readers a view, not an API to edit admission. I found no supported producer requirement to mutate admitted structure during participant callbacks. Aggregation before admission is legitimate construction and must remain possible. These facts justify an explicit source-owned structural boundary; they do not justify freezing caller rows, proof cells, or arbitrary structural objects shared elsewhere.

**Recommend A for the bounded next experiment.** B is a cheaper correction to the specific finalizer bypass, not a general stable-admission mechanism. Do not add a fifth native check. Do not claim B establishes a coherent packet merely because the final array matches.

Concrete B counterexample (source-only proposed discriminator, not executed): a private recipient appends edit 99 in prepare; a subsequent recipient consumes/enqueues 99; the first recipient finalizer removes it. Final validation sees the original array, while native responsibility selected 7 and a recipient selected 99. Four local checks can also miss this when mutation occurs after native preparation. If private mutation is explicitly unsupported, B can be described as best-effort diagnostics only; it cannot retain the stronger refusal/coherence claim. Making B sound requires every reader to use a canonical captured structure, which is effectively A.

## Smallest concrete A mechanism

1. **Own metadata at issuance.** Finish source edits/steps before exposure. Retain each original `EntityPublicationEdit` object as the key for `forEdit`, pairing and restoredFields lookup; do not clone edits to populate the index. Source-created edit shells become shallow immutable records at admission. Arrays for ordinary/physical membership, step order, step membership, field names and order ids become source-owned immutable arrays. Source-created step shells and authored-footprint metadata become immutable. For shared structural descriptors, create the source-owned descriptor shell when constructing the publication edit, before that edit identity is issued; do not freeze an upstream shared effect in place. Its scalar admission facts cannot subsequently change. Caller `before`/`after` values remain referenced, not recursively frozen or cloned. Requirement/endpoint objects and restoredFields proof values retain their established lifecycle; this is not proof immutability.
2. **One common entrance.** Establish this boundary in the source issuance/admission path before native preparation, fallback responsibility or recipient preparation. Deferred point packets must have stable fragments when queued, while the group container remains appendable; seal the final aggregated membership once before `source.prepare`. Do not repeatedly traverse/reseal stable fragments at every nesting level. A private per-preparation descriptor/brand may record ownership; no global cache or authority index. Direct private test packets must enter the same normalization/ownership boundary; no unguarded test-only route.
3. **One ordered index.** Build the ordinary admitted sequence and last-subject lookup once for the final unit. Iterate actual step-array order, including empty steps; apply existing same-step authoredRemoval dedup exactly. Keep duplicates and repeated references; last lookup includes removal, rekey and partial edits. Use original edit identity for step-local pairing and restoredFields precedence. Do not sort by ordinal or deduplicate the processing sequence. Retained support captures the same admitted subject domain, never re-enumerates mutable external arrays.
4. **Small point representation.** For a genuinely one-edit final unit, use its stable original sequence and a direct last-edit comparison rather than allocating a redundant Map plus copied subject list. Determine cardinality from the admitted unit, not observer count or resident collection size. Multi-edit lookup stays local Map-based; a singleton shortcut must not collapse multiple same-subject occurrences or lose step-local evidence. Preserve source proof even with zero recipients.
5. **Existing install frontier.** Native and recipient finalizers still all run before install; source revision, recipient revision, retirement/disposal and public reentry checks remain. Stable structure removes the need for four rescans, not for those checks. No callback between the final source validity check and installation may create a new unvalidated source frontier. Completion retains installed-record semantics and throw/reentry behavior.

This is a finite producer/admission change, not simply Object.freeze(packet): shallow freezing only the outer packet leaves nested arrays and edit subjects writable. Conversely recursively freezing the reachable graph is incorrect. A producer audit must identify shell/array ownership for both frame and point paths. Any genuinely shared mutable metadata must be projected into the source-owned descriptor before exposure, preserving the issued edit identity; do not silently freeze it in place. RestoredFields remains edit-specific, not indexed by subject as a substitute. No proposal to redesign its existing proof authority is included here.

## Private mutation outcome and evidence preservation

A changes unsupported mutation behavior deliberately: mutation through the exposed stable metadata cannot alter admission (strict writes may throw). A private callback that catches its own failed write may continue with the unchanged unit; there is no need to invent a policy that every attempted mutation poisons the operation. Source-owned copied array containers may mean mutation through an obsolete external array has no effect. Such behavior is different from the current guard's bespoke error text.

Preserve the independent original exact refusal test and its first red. If canonical copying makes that external-array probe no longer address the admitted array, add a clearly labeled discriminator that mutates the actual packet received by a recipient, plus assertions that native/recipient/responsibility endpoints agree and no stale record installs after an escaping error. Do not relabel the original assertion as passing, silently edit its error string, or indiscriminately translate arbitrary callback TypeErrors into admission errors. Source public reentry remains a separate unchanged mandatory refusal control.
