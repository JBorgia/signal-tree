# Human/agent application evaluation

Private consumer fixtures for the [registered investigation](../../docs/audits/2026-11-11-agent-collaboration/PROTOCOL.md).
These tools do not add a public package, configuration mode, security service or
agent SDK. Use the pinned Node version and serialize builds, tests and measurements.
Every output directory must be new; preserve failed attempts.

## What each result establishes

| Tool | Evidence | Important limit |
| --- | --- | --- |
| `public-workflow.mjs` | Installed native state, optional operation coordinator, protocol adapter, HTTP authority cases and production Angular DOM checks | HTTP/native tests and the original DOM fixture are separate integrations |
| `http-browser/run.mjs` | Actual browser fetch, immutable review, separate host approval, command receipt, native settlement and retryable cleanup | In-memory authority; no production authentication, durable restart, human-presence proof or cross-tab protocol |

| Existing `application-lab/profile.mjs` | Separate sampled attribution and browser duration telemetry | Instrumented observations are not comparative timings or exact per-function CPU |

## Installed public workflows

Configuration binds one artifact plan, its source identity, exact kernel and
Angular archives and their integrities. Both runners admit those archives before
installing and compiling strict production AOT consumers. The browser/HTTP runner
requires exact equality between archive and installed package inventories.

```sh
node tools/agent-collaboration-lab/public-workflow.mjs CONFIG NEW_OUTPUT
node tools/agent-collaboration-lab/http-browser/run.mjs CONFIG NEW_OUTPUT
node tools/agent-collaboration-lab/http-browser/run.mjs CONFIG NEW_CONTROL_OUTPUT --control=skip-native-settlement
node tools/agent-collaboration-lab/http-browser/run.mjs CONFIG NEW_CONTROL_OUTPUT --control=ignore-instance
```

The [browser/HTTP protocol](http-browser/PROTOCOL.md) lists intermediate oracles
and the boundary between the browser transport, trusted approval host and backend.
Read it before treating a passing fixture as a product capability claim. The
coordinator and test authority remain repository references; they are not newly
shipped kernel APIs.

## Production application metrics

`prepare-packet.mjs` verifies the predecessor's inputs and exact successor package
inventories, then creates a separate packet. It grants no build or conformance
credit. Pinned rivals and common application strategies remain unchanged.

```sh
node tools/agent-collaboration-lab/prepare-packet.mjs CONFIG NEW_PACKET
node tools/application-lab/lab.mjs build NEW_PACKET
node tools/application-lab/lab.mjs build-dispatch NEW_PACKET
node tools/application-lab/inventory-check.mjs NEW_PACKET
node tools/application-lab/dispatch-check.mjs NEW_PACKET
node tools/agent-collaboration-lab/measure.mjs controls NEW_PACKET NEW_CONTROLS
node tools/agent-collaboration-lab/measure.mjs calibrate NEW_PACKET NEW_CALIBRATION
node tools/agent-collaboration-lab/measure.mjs compare NEW_PACKET NEW_COMPARISON NEW_CONTROLS/results.json NEW_CALIBRATION/results.json
node tools/agent-collaboration-lab/analyze.mjs NEW_COMPARISON NEW_ANALYSIS
node tools/application-lab/source-inventory.mjs NEW_PACKET NEW_SOURCE_INVENTORY.json
```

The [metric protocol](metrics-protocol.md) fixes six arms, two row counts, separate
fresh timing/memory browsers, five rounds and same-build controls. It distinguishes
startup, context materialization/serialization, pending pressure, settlement,
synthetic user responsiveness, frame-callback observations and whole-app retained
heap. No model inference, token cost, real-user INP or human productivity is measured.

Historical prose is resolved only by an explicit original-path/hash allowlist
against the verified evidence manifest. Loaded, compiled, served and executed
inputs must match their current exact bytes. `historical-inputs.test.mjs` contains
missing, corrupt, unlisted and executable-drift controls. The historical resolver
does not make stale runtime results fresh.
