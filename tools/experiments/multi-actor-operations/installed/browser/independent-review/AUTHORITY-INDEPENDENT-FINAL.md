## Integration reasoning

Apply constructs the same immutable binding/JSON tuple command ID as coordinator
approval. The trusted reviewer context is host-held; protocol arguments cannot
supply it. The transport calls the review gate before DispatchBackend. Unknown actor
attribution remains unknown. A backend permission boolean is no longer the sole
stand-in for review consent in this dispatcher path. The service capacity fixture
uses a separate direct backend path; this review does not claim all backend callers
are gated or that browser same-realm code is a security boundary.

One active operation retains the exact grant across uncertain delivery. Terminal
receipts revoke it before native settlement; retained outcome/native handle enable
local-only retry without resending. Native pending presence and the matching terminal
lifecycle event are checked separately: an empty pending list alone cannot assert
confirmation/rollback. Overlap refusal retains the owner; post-terminal observer
throw reports the error while preserving the observed disposition. The corrected
local-refusal case is reproduced by both original and additional tests.

Observation is captured before constructing the producer stream and closed over by
the host builder; protocol output cannot replace it. Browser generation is still
synchronous. The independent delayed-observation protocol controls establish that
separate seam, not end-to-end remote streaming/HTTP timing.

## Limits that remain open

ngOnDestroy still calls the refusal-capable dispose function; Angular destruction
cannot be vetoed. The old independent uncertain/in-flight destruction failures
remain applicable as a documented boundary. A route/session owner that outlives
components or durable recovery is not implemented. The final result qualifies
explicit disposal controls only, not cleanup during unresolved actual destruction.

A real success/confirm-throw path remains unestablished; the accepted-plus-later-work
probe is not a substitute. Original checks collect pageerror only; added probes also
collect console errors. Grant-count is app instrumentation, not direct Map inspection;
actual capacity rejection and useful reuse are exercised. This integration review
does not duplicate or replace the separately assigned standalone authority audit.
