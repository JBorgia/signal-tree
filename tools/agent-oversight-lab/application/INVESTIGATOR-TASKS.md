# Dispatch workspace investigation

This kit evaluates the information visible to an investigator. A functional
browser test is not a usability study. Simulated agent answers and real human
participant answers must be recorded separately.

For each independently supplied view A–E, answer from visible evidence only:

1. Who is authenticated as the proposer? What do you know about the agent's
   identity? Who, if anyone, approved the request?
2. What did the authority apply, reject or leave unknown? Explain which visible
   fact supports the answer, and distinguish a proposal from an effect.
3. Is any local ownership unresolved? If several operations exist, distinguish
   them using the request's business change or command identity.
4. Does the view establish a complete event history? Identify missing evidence.
5. What is a safe next action? What additional information would you request
   before taking it?

If the interface does not provide an answer, say what is unknown. The answer
key, generator and prior reviewers' findings must not be shown to participants.

For real participants, record consent, relevant application experience, task
order, elapsed task time, answer, confidence, requested assistance and the
specific visible evidence used. Rotate view order. Do not solicit confidential
customer data. Use the fixture identities supplied with the kit. Count incorrect
claims of authorization, effects or complete history separately from ordinary
navigation mistakes. Preserve failures and participant comments.

The owner has not approved a population, sample size, success threshold or
recruiting arrangement. This prepared kit cannot establish human comprehension
until actual participants complete it. Automated and independent agent results
can expose misleading labels; they cannot substitute for that evidence.
